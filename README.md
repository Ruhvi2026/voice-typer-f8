# 🎙️ Bangla Voice Typer for Antigravity IDE & Windows

একটি আধুনিক, আল্ট্রা-লাইটওয়েট এবং অত্যন্ত নিখুঁত বাংলা স্পিচ-টু-টেক্সট অ্যাপ—যা সরাসরি আপনার ল্যাপটপের বিল্ট-ইন মাইক্রোফোন ব্যবহার করে মুখে বলা বাংলা কথা মুহূর্তের মধ্যে Antigravity IDE (বা যেকোনো উইন্ডোজ অ্যাপ)-এ স্বয়ংক্রিয়ভাবে টাইপ করে দেয়।

---

## ⚡ প্রধান সুবিধাসমূহ (Key Highlights)

1. **পিসিতে কোনো চাপ নেই (Near-Zero RAM Footprint):**
   - মাত্র **~২৫-৩০ MB RAM** খরচ করে। আপনার ৪ জিবি র‍্যামের সিস্টেমে কোনো প্রকার ল্যাগ বা হ্যাং ছাড়াই স্মুথলি চলে।
2. **সর্বোচ্চ নির্ভুল বাংলা ইঞ্জিন:**
   - গুগলের ক্লাউড স্পিচ ইঞ্জিন ব্যবহার করে, যা শুদ্ধ বাংলা এবং ইংরেজি কোডিং পরিভাষা (যেমন: "React component", "bug fix", "button add koro") নিখুঁতভাবে বোঝে।
3. **সরাসরি কার্সরে অটো-পেস্ট (Auto-Paste):**
   - Antigravity IDE-র চ্যাট বক্স বা এডিটরে কার্সর থাকা অবস্থায় আপনি কথা শেষ করলেই স্বয়ংক্রিয়ভাবে টেক্সট পেস্ট হয়ে যায়।
   - এটি আপনার আগের ক্লিপবোর্ড ডেটা নষ্ট করে না (আগের কপি করা টেক্সট অক্ষত থাকে)।
4. **স্মার্ট সাইলেন্স ডিটেকশন (Auto-Stop):**
   - আপনি কথা শেষ করে একটু থামলেই এটি নিজে নিজেই রেকর্ড বন্ধ করে রূপান্তর শুরু করে।
   - চাইলে আপনি দ্বিতীয়বার একই হটকি চাপ দিয়েও সাথে সাথে থামিয়ে দিতে পারেন।
5. **আধুনিক ভিজ্যুয়াল ও অডিও ফিডব্যাক:**
   - স্ক্রিনের ডানদিকের নিচে সুন্দর ডার্ক-মোড পিল ব্যাজ দেখায় (`🎙️ শুনছি...` -> `⏳ রূপান্তর হচ্ছে...` -> `✅ টাইপ হলো...`)।
   - কথা শুরু ও শেষের সময় হালকা মিষ্টি বিং সাউন্ড বেজে ওঠে।
6. **সিস্টেম ট্রে কন্ট্রোল (System Tray):**
   - টাস্কবারের ঘড়ির পাশে মাইক্রোফোন আইকন থাকে। রাইট ক্লিক করে আপনি সহজেই:
     - ভাষা পরিবর্তন করতে পারবেন: **বাংলা (ভারত - bn-IN)** অথবা **বাংলা (বাংলাদেশ - bn-BD)**।
     - সাউন্ড ইফেক্ট বা ভাসমান নোটিফিকেশন অন/অফ করতে পারবেন।
     - এক্সিট (Exit) করতে পারবেন।

## 🚀 কীভাবে ব্যবহার করবেন (How to Use)

### ১. অ্যাপটি চালু করা:
- আপনার ডেস্কটপে থাকা **`Bangla Voice Typer`** আইকনে ডাবল-ক্লিক করুন।
- এটি কোনো কালো কনসোল উইন্ডো ছাড়াই ব্যাকগ্রাউন্ডে নীরবে চালু হবে এবং স্ক্রিনে `🎙️ Bangla Voice Typer প্রস্তুত!` মেসেজ দেখাবে।

### ২. Antigravity IDE-তে মুখে বলে টাইপ করা:
1. Antigravity IDE-র চ্যাট বক্সে বা এডিটরে মাউস দিয়ে কার্সর রাখুন।
2. কীবোর্ডের **`F8`** (অথবা **`Ctrl + Alt + B`**) চাপুন।
3. একটি মিষ্টি সাউন্ড হবে এবং স্ক্রিনে আসবে: **"🎙️ শুনছি... মুখে বলুন"**।
4. বাংলায় কথা বলুন (যেমন: *"একটা কাউন্টার কম্পোনেন্ট বানিয়ে দাও"* বা *"এই বাগটা ফিক্স করো"* )।
5. কথা বলা শেষ হলে একটু থামুন—স্ক্রিপ্টটি স্বয়ংক্রিয়ভাবে তা বাংলায় রূপান্তর করে **Antigravity IDE-তে টাইপ করে দেবে!**

## 🛠️ ফাইল ও ফোল্ডার তালিকা:

* `app.py`: মূল অ্যাপ্লিকেশন ইঞ্জিন।
* `start_silent.vbs`: কোনো কনসোল উইন্ডো ছাড়া ব্যাকগ্রাউন্ডে চালু করার স্ক্রিপ্ট (ডেস্কটপ শর্টকাট এটিই ব্যবহার করে)।
* `run.bat`: কোনো সমস্যা দেখতে চাইলে টার্মিনাল সহ চালু করার স্ক্রিপ্ট।
* `test_voice.py`: টার্মিনালে ৫ সেকেন্ডের জন্য ল্যাপটপের মাইক ও গুগলের বাংলা রিকগনিশন টেস্ট করার টুল।
* `settings.json`: কনফিগারেশন ফাইল।
